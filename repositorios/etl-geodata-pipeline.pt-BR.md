# ETL de geodados

**Repositório original:** https://github.com/Manoela-Calabresi-Portfolio/ETL-Geodata-Pipeline

Pipeline reprodutível para baixar, limpar, padronizar e organizar dados geoespaciais abertos. O foco está em transformar bases públicas dispersas em insumos consistentes para análise territorial, mapas e indicadores.

## Problema que o projeto resolve

Bases territoriais públicas costumam chegar em formatos heterogêneos, com estruturas distintas e alto custo manual de preparação. O pipeline reduz esse atrito e organiza uma base reutilizável.

## Bases utilizadas

- APIs territoriais;
- camadas geoespaciais abertas;
- dados administrativos;
- formatos vetoriais para análise posterior.

## Método

- download automatizado;
- limpeza e padronização;
- organização por tema e origem;
- exportação de camadas tratadas;
- documentação do fluxo analítico.

## O que o projeto entrega

- bases tratadas para análise;
- camadas georreferenciadas;
- estrutura reprodutível para novos estudos;
- apoio técnico para mapas e indicadores.

## Ferramentas

- Python
- GeoPandas
- DuckDB
- ArcGIS REST API

## Relevância

- análise de dados secundários;
- georreferenciamento;
- dados administrativos;
- organização de bases públicas;
- infraestrutura analítica territorial.
